Como funciona

Três passos. Nada para instalar.

  1. 01

    Geras um link

    Escolhes quanto tempo a conversa dura: uma hora, um dia ou uma semana. Recebes um link e um código QR.

  2. 02

    Convidas uma pessoa

    Envias o link por onde quiseres. Escreve o nome dela e entra. Só uma pessoa — a segunda é recusada.

  3. 03

    Conversam. Depois desaparece.

    Mensagens, chamadas de voz e confirmação de leitura. Quando o tempo acaba, apaga-se sozinho.

Privacidade

A chave nunca chega ao servidor.

O link tem duas partes. A que o servidor vê, e a que nunca lhe chega.

sala.app/s/K7PQ2M#k=Xy9a...bK2
Vai ao servidor Nunca sai do teu aparelho

Cifrado antes de sair

Cada mensagem é fechada à chave no teu browser com AES-GCM 256. O servidor recebe texto que não consegue ler.

Apaga-se sozinho

Não é código a limpar depois. A própria base de dados esquece no prazo marcado, sem exceções.

Nada a preencher

Sem email, sem número, sem perfil. Não há conta para invadir nem lista de contactos para vazar.

Chamadas directas

A voz vai de um aparelho para o outro sem passar pelo servidor. Nem sequer existe algo para gravar.

Ao certo

O que isto não faz.

  • Quem tiver o link completo entra. Escolhe bem por onde o envias.
  • A lista de conversas vive no teu browser. Se o limpares, perdes o acesso.
  • Nada impede a outra pessoa de fotografar o ecrã. Isso nenhuma app resolve.
